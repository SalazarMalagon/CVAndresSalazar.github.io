Co-founder & Head of Engineering

CareFlow Solutions · Bogotá, Colombia
Jun 2026 – Present

SaaS platform for assisted clinical documentation for nursing teams: nurses fill in guided fields and CareFlow generates a standardized, traceable clinical note ready for review and approval.

  • Architected and built the product end to end: web frontend and Supabase backend (PostgreSQL, Edge Functions).
  • Designed a multi-institution model with data isolation through Row Level Security, user, role and session management, and per-institution branding.
  • Modeled clinical data: patients, auto-saved drafts, note confirmation, shift-to-shift continuity, and retention policies.
  • Built a clinical rules engine generated automatically (Python) from the nursing-validated clinical book, with auditing and traceability for every rule.
  • Implemented the shift handover modules with a keyboard-optimized experience and a custom design system.
  • Set up quality assurance with unit, integration, database (SQL) and end-to-end tests (Playwright).
  • Built CI/CD with GitHub Actions and separate development, staging and pilot deployments, including environment checks, backups, key rotation and security controls.
  • Worked directly with nursing professionals to translate clinical needs into software requirements.
